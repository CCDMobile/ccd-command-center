👁 Packing Slip Field Visibility
Control which fields appear on printed slips. These apply to all profiles (they're global, not per-profile). Pricing columns are still chosen by the Slip Type dropdown at print time (Standard / Priced / Gift). When a sale has no price recorded, price cells render empty — never "$0.00" — so customers aren't confused.
Standard / Priced Slips
Applies to both Standard (no prices) and Priced (with prices) slip types.
Return Instructions Text (v2.9.4)
Global text shown on Standard / Priced slips when "Show Return Instructions block" is on. One text applies to all profiles. Leave empty to suppress (block won't render even if toggle is on).
Gift Slips

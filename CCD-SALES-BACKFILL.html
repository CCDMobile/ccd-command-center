🏠 Wayfair Proxy

ℹ️ How It Works

1. Pulls orders from Wayfair API using fromDate pagination
2. Matches Wayfair partNumber to items via wayfair_sku
3. Joins cost data (wholesale, IB shipping, tariff) from items table
4. Writes to sales_history with WF-{poNumber} format
5. Skips orders already in sales_history (duplicate-safe)
6. Client-side filtering for end date (Wayfair has no toDate)

Prerequisite: Wayfair proxy v1.1.8+ with fromDate support.

🛒 Etsy Proxy

ℹ️ How It Works

1. Pulls receipts from Etsy API using min_created/max_created
2. Each receipt contains transactions (line items) with SKUs
3. Matches Etsy SKU to master items via exact match or etsy_sku
4. Joins cost data (wholesale, IB shipping, tariff) from items table
5. Writes to sales_history with ETSY-{receipt_id} format
6. Skips orders already in sales_history (duplicate-safe)

Prerequisite: Etsy proxy v1.0.8+ with auto-pagination on getOrders.

🌐 Wix Proxy

ℹ️ How It Works

1. Pulls all orders from Wix eCommerce API with auto-pagination
2. Client-side date filtering (Wix API doesn't support date range queries)
3. Matches Wix SKU to master items via exact match or wix_sku
4. Joins cost data (wholesale, IB shipping, tariff) from items table
5. Writes to sales_history with WIX-{order_id} format
6. Skips orders already in sales_history (duplicate-safe)

Prerequisite: Wix proxy v2.0.8+ with date filtering on getOrders.
